# SDRoxide 简体中文语言插件

当前汉化基于 SDRoxide 1.6.9 上游提交 `591d21d0b1bcddfcc7aaab8146141c953727e616`。语言包版本为 `0.2.1-preview`，状态仍为 `partial`：源文案和手册覆盖已扩展到此上游版本，完整窗口布局、安装／恢复路径及硬件验收尚未全部完成。原始 checkout 保持未修改；实际汉化宿主与资源位于独立副本。

运行时目录有 5,343 个简体中文词条，含 5 个新上游 FT8 解码深度标签和提示。LimeSDR Mini 新增采样率使用已有速率说明译文；呼号、协议名、单位、地址、消息正文及用户输入按原值保留。新文案在插件关闭或上游原文发生变化时回退英文。FT8 新增文案的启用、停用和源文本变化回退测试已通过。

F1 中文手册当前覆盖 987,045 个源字符，244 个翻译片段；章节、代码围栏和链接目标检查通过，244 个片段均有与当前译稿哈希匹配的审校记录。针对这次上游新增的 FT8 解码深度、NAVTEX 频偏容差和 LimeSDR Mini 采样率说明，已补齐译文并完成源码对照。手册缺失、上游文档指纹变化或结构不兼容时，手册独立回退英文。

语言包使用独立 JSON 目录和 Noto Sans SC 字体，字体许可证为 OFL，见 `fonts/OFL.txt`。语言包不含 DLL、可执行脚本或电台控制代码。上游原版没有此加载接口；需使用随附的汉化宿主，设置 → 界面 → 语言包可启用、停用或导入语言包。语言偏好保存在独立设置文件，不覆盖 SDRoxide 原配置。

当前证据：全量 UI 单元测试 797 项通过；语言包测试 5 项通过，字体和内置包测试 3 项通过。测试环境使用无电台后端；未执行发射或 PTT 操作。完整设置页和原生窗口布局验收仍待补足，最新版 Windows EXE 和安装／恢复包也需按当前上游重新构建并复测。`manifest.json`、`translations.csv`、`integration-report.json` 与 `validation.json` 提供机器可读清单和验证记录。
