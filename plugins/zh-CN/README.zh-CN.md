# SDRoxide 简体中文语言包

本语言包当前适配 SDRoxide **1.6.10**，对应上游 `dividebysandwich/sdroxide` 的 `main` 提交 `75b549b388a14b706e529289b9de970b0abd7fb4`。语言包版本为 **0.2.5-preview**。它以独立插件资源提供译文、中文字体和手册，不替换或改写原始英文文本；原文缺少译文、插件关闭或语言包不兼容时，界面会回退到英文。

语言目录包含 **5,409 条** UI 译文，随包提供 Noto Sans SC 字体（OFL 许可，见 `fonts/OFL.txt`）。保留呼号、协议和模式标识、频率与单位、设备名称、动态数据以及用户输入。插件代码不包含发射控制逻辑。

`manual.zh-CN.json` 提供完整简体中文用户手册，覆盖当前 `docs/USER_MANUAL.md` 的 **250 个审校片段**。上游手册哈希、译文资源哈希及逐项审校记录见 `manual-review-75b549b3.json`；源手册改变或格式不兼容时，宿主应回退到英文帮助。

## 当前验证

2026-10-18 在 Windows 工作副本重新运行：`sdroxide-language-pack` 的 **5 项单元测试及 3 项内置语言包／字体／手册测试全部通过**；`sdroxide-ui --lib` 的 **812 项测试全部通过**。UI 测试包含插件开关、缺失译文回退、保留动态值，以及 1.6.10 卫星过境和转台标签中英文切换检查。对 UI 源码中的 3,651 个不同字面 `text/format` 调用键进行目录核对，缺失数为 0。测试没有连接真实电台，也没有执行发射、PTT 或转台硬件操作。

当前工作副本的上游 `main` 已与 `75b549b3` 同步，未发现更新提交。原始 checkout 未修改。

## Windows 可执行文件状态

上述测试验证的是当前源码与独立语言包资源。当前环境未能构建适配 1.6.10 的新版 Windows EXE：构建依赖 SoapySDR/PothosSDR，且 MSVC 环境缺少 Rade 构建所需的可用 C 编译器。因此目前没有与本版 1.6.10／0.2.5-preview 对应的新安装包或切换器 EXE；请勿将旧版本可执行文件当作本版验证产物。

发布包重建、Windows 原生设置／帮助页完整截图验收仍需在具备依赖的 Windows 构建环境中完成。所有验证保持接收测试边界。
